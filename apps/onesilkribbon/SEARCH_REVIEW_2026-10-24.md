# 丝带站手机体验与搜索流量检查（2026-10-24）

本次范围为 onesilkribbon.com。未修改玻璃站、数据库、支付逻辑、商品价格或库存。

## 目前能确认的情况

- 修改前公开站点地图有 27 个网址，其中商品页 12 个、已发布文章 1 篇、非空分类 5 个。站点地图不是已收录列表，这些数字不能代替 GSC 的索引报告。
- robots.txt 返回 200，允许抓取公开页面，仅禁止 /api/。已检查的首页、分类及部分商品页返回 200，具有对应 canonical 和 index, follow；没有发现整站 noindex。
- http 及 www 首页实测永久跳转到 https://onesilkribbon.com/；默认分享图返回 200。不能据此保证所有历史 URL 或所有页面都正常。
- 公开搜索可找到首页、商品及护理指南等页面，搜索结果中也出现较早的文案与 www 地址。公开搜索不是 Google 索引数量或排名的完整证明。
- 分类页正文比较简略：公开 HTML 简单去标签计数约 36–95 个英文词，主要是标题、商品名及一句介绍。这不是 Google 的字数门槛，但实际缺少对宽度、长度、用途与商品差异的解释。
- 分类文案存在事实错配：Fine Silk 写 2–10mm，实际商品为 2–13mm；饰品分类写发圈，实际为迷你蝴蝶结和刺绣胸针；工具分类写剪刀等，实际有木线轴。部分备用描述还未经核实声称在英国制造。
- 首页在商品之前展示全部系列及品牌故事，手机找商品需要较多滚动；首屏文案原本要等 JavaScript 设置状态才从透明变成可见。
- 手机新访客原来可能在 3 秒后遇到锁住页面的促销弹窗。该弹窗会打断阅读；不能仅凭它认定网站被降权。
- Fine Silk 公开商品页实测 HTML 解码后为 1,317,238 字节，包含 145 个规格；ProductGroup 约 530,857 字节，每个规格重复 30 张通用图片。这是传输及解析负担，不等同于真实 LCP 或 PageSpeed 分数。
- 本地一次商品导航超时后显示 404，随后同一商品的公开搜索及直接查询均能找到它。代码检查发现：商品读取错误原来与无数据一样返回 null，可能误触发 notFound；尚不能量化这种错误在线上的频率或流量影响。

## 本轮处理

1. 手机及平板不再自动打开促销弹窗，首页提供正常文档流中的优惠入口，主动点击才打开。桌面原有邀请、邮件验证成功/失效结果及关闭行为保留。
2. 首页首屏文案直接可见；减少对 JS 状态和延迟动画的依赖。降低动态效果偏好的访客不自动轮播，页面在后台时不继续切换图片。
3. 首页实际商品展示提前到系列列表之前，推荐卡片长标题允许收缩换行；系列列表只展示有上架商品的系列。
4. 分类总览显示真实商品图片、数量及有商品的分类；手机标题与数量分行，避免挤压和裁切。数据库查询失败时不发布一个虚假的空列表。
5. 分类正文与 metadata 共用一份内容，修正宽度、用途及品类错配；补充选购说明，并链接到护理、配送及新指南。暂时查不到分类数量时不会误发 noindex。
6. 新增 /ribbon-guide：说明项目用途、宽度、边缘、测量样本和长度估算，包含商品分类及配送链接，接入站点地图和页脚。没有批量生成色号页、伪造销量/评论或制造产地。
7. 商品页只在手撕丝带系列显示手撕边缘故事，避免木线轴、迷你蝴蝶结或平边丝带被统一描述为手撕。去掉未核实的英国制造备用描述与部分固定色号数量。
8. 商品读取或规格读取错误会明确失败，不再当成商品已删除或没有规格；真正不存在的商品仍保留 404。
9. 商品结构化数据保留全部规格、报价和库存，每个规格提供对应代表图，优先 SKU 图片、再选中属性图片、最后通用首图。完整相册仍保留在产品组及页面；Feed 同样使用匹配规格的图片。

## 对低流量的判断边界

目前可以确认内容覆盖有限、分类信息及用途定位不够准确、手机浏览受到打断。这些都是值得改进的问题，但还不能量化它们分别造成多少流量损失。

如果“每周十几”指展示次数，那么首要现象是搜索曝光少，而不是单凭一两次点击就断定点击率很差。GSC 的展示、点击、CTR、排名与网站总访客数是不同指标。GA4 的同意门控可能影响 GA4 统计，不能解释 GSC 的搜索展示或点击量。

尚未读取 GSC 的私有报告；已请求最近 3 个月总展示、总点击、平均排名及已收录页数。取得查询词、页面、国家、设备数据后，还需判断：

- 商品和分类是否已收录，未收录原因是什么；
- 有展示的具体搜索词及对应页面，是否与产品用途匹配；
- 是排名太靠后、搜索需求少，还是有排名却没人点击；
- 历史 Shopify 路径是否产生 404、旧 URL 是否准确跳转；不能未经映射将所有旧页跳到首页；
- Google Merchant Center 免费商品展示是否已启用、Feed 是否被接受；本轮仅确认网站存在商品 Feed，未读取 Merchant Center 账户；
- 真实移动访客的 LCP/INP/CLS。PageSpeed API 本次请求未得到有效结果，不能提供或声称手机速度分数；本地网络的单次响应时间不等同于真实用户性能。

## 建议后续顺序

先核对 GSC 索引与实际搜索词，优先改善有展示的商品/分类。再围绕真实客户问题补充项目实拍、对比样本和原创教程。可考虑细带刺绣/玩偶衣饰、手撕丝带婚礼花束、长度计算等主题，但不声称这些词的搜索量或竞争难度已经验证。

商品素材、真实项目照片、客户许可的使用反馈，以及相关创作者/花艺师的自然推荐，需要店主参与；仅靠反复调整样式或标题，不能保证持续增加搜索需求或排名。
