# 丝带站检查与本轮优化（2026-10-23）

范围：`apps/onesilkribbon` 与本仓库的 `packages/core`。玻璃站独立仓库未改动；未修改生产数据库、创建订单、扣款、退款或发送邮件。

## 已修复

- 搜索：取消过期请求，防止旧结果覆盖新关键词；清空短关键词的加载状态，限制输入长度，支持 Escape 关闭。
- 商品：首页不再取停用规格的价格；详情页同步推导所选 SKU，避免规格和加入购物车的 SKU 短暂不一致。
- 购物车：菜单与购物车共享滚动锁；隐藏时不再留下可聚焦控件；增加弹层键盘焦点管理。
- 运费：购物车打开时再查询，减少全站无用请求；统一配置解析，错误数据不再变成零运费，保留合法的零门槛和小数门槛。加载前不显示默认运费或确定总额，结账在真实配置加载前禁用付款；失败或超时显示刷新提示。
- 结账：支付链接创建失败时明确展示错误，不再出现点击后无提示的情况；移除没有对应统一政策依据的“30 天退货”固定承诺，改为按退货政策适用。
- 首页：正确清理滚动观察器；不支持动画或偏好减少动态效果时保留内容可见。
- 登录：使用 Supabase SSR 解码分块、base64 会话 Cookie，仍向认证服务器验证用户；明确的无效 Bearer 不再切换成另一个 Cookie 身份。
- SEO：网站地图并行查询，不伪造每小时更新的日期；数据库异常时拒绝生成残缺地图。保留现有首页文案与摘要优化。
- 后台：商品/SKU 查询失败不再返回成功的空数据；删除前核对历史订单失败则停止；检查每次删除/下架的错误；阻止编辑器提交其他商品或过期的 SKU ID。
- 库存：管理员主动修改库存也比较最初加载的库存，若期间发生新订单则返回冲突，避免覆盖新库存。
- 依赖：Next 14 → 15.5.28、React 19.3.1、Sentry 10.76.2、sanitize-html 2.18.1 及兼容的间接安全补丁；已适配异步路由参数和商品数据源缓存。
- 监控隐私：新版 Sentry 不允许通过 `beforeSendSpan` 返回 null 丢弃数据，现改为失败时返回空的已脱敏对象，并对真实 SDK 的输出封装做回归验证，避免恢复原始敏感 span。

## 验证

- 113 个自动测试通过，包含库存/优惠券数据库事务、支付重试与恢复、敏感表权限、隐私、内容过滤及本轮新增测试。
- 生产构建通过；锁文件 `npm ci --dry-run --ignore-scripts` 校验通过；依赖树无 React 多版本冲突。
- 浏览器实测：首页、搜索、短关键词清空、商品跳转、规格价格切换及购物车规格一致性。
- 只读 HTTP 检查：首页、系列、登录、结账、确认页、网站地图、robots、Google Feed、设置与搜索正常；无登录用户接口和带伪造身份头的后台接口返回 401。
- 未验证真实支付平台扣款、退款、邮件投递及真实管理员登录；这些不属于无副作用的自动冒烟测试。

## 尚未完成／后续建议

1. 原剩余 3 条依赖告警：已在用户明确确认后的 Next 16 专项升级中处理，详见下文；扫描清零不代表业务逻辑绝对无漏洞。
2. 商品及其多个 SKU 的保存仍是多次数据库写入；本轮改为报告失败并阻止危险后续步骤，但还不是整个商品编辑的单个原子事务。若要实现全成全败，需单独设计数据库 RPC 和迁移。
3. 构建仍有既有的 Hook 依赖、普通 img 元素及 Sentry 客户端配置文件弃用提示，非构建错误；可继续分批收敛。

本记录是本轮确认的问题和验证证据，不构成“全站绝对无漏洞”的保证。未提交或清理用户的 `.claude/` 目录。

参考：[Next 15 迁移](https://nextjs.org/docs/app/guides/upgrading/version-15)、[AVIF 安全公告](https://github.com/vercel/next.js/security/advisories/GHSA-2xp9-vwfh-vxw4)、[SVG 安全公告](https://github.com/vercel/next.js/security/advisories/GHSA-2464-fhr4-w9xw)。

- 用户明确确认后，先在 `codex/next16-security-upgrade` 独立分支验证。
- Next 与 third-parties 升至 16.4.3；React 19.3.1、支付 SDK、数据库 schema 和权限设计未改。
